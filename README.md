# weather_forecast

A new Flutter project.

## Getting Started

A Flutter-based weather application that displays real-time weather
information using a public REST API. The app provides current temperature,
weather conditions, and location-based forecasts with a clean UI.

## Features
- Real-time weather data using REST API
- Search weather by city name
- Clean and responsive UI
- Error handling for invalid locations
- Lightweight and fast performance

## Tech Stack
- Flutter
- Dart
- REST API
- HTTP Package
- GetX (State Management)
- syncfusion_flutter_gauges (Progressbar for Humidity Section)
- percent_indicator
- hive:
- hive_flutter
- hive_generator
